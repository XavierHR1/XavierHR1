## 👨‍💻 About me

I'm studying an **Advanced Vocational Training programme in Multiplatform Application Development (DAM)** at **Institut Baix Camp in Reus, Spain**. I enjoy building useful applications, learning new technologies, and understanding the full development process: from user interfaces to application logic and data.

- 📱 **Android:** building applications with **Kotlin**, **Jetpack Compose**, and **XML** layouts.
- 🌐 **Web:** development with **HTML, CSS, JavaScript, TypeScript, React, Next.js, Tailwind CSS, and Node.js**.
- 🗄️ **Programming and data:** academic experience with **Java, Python, PHP, and SQL**.
- 🧩 **ERP:** academic experience with **Odoo**, creating custom modules in **Python** and modifying built-in ERP modules to adapt their functionality.
- 🤝 **Community:** interested in teamwork, programming challenges, and technology events.
